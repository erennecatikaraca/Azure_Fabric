# Microsoft Fabric Lakehouse Lab: Sales Data Analysis

## 📌 Overview
This lab demonstrates a **end-to-end data analysis workflow** using Microsoft Fabric's Lakehouse. It covers:
- Creating a Lakehouse workspace
- Ingesting and exploring sales data (`sales.csv`)
- Visualizing product quantities using Power BI integration

## 🛠️ Lab Steps
1. **Workspace Setup**
   - Created a new Fabric workspace with Lakehouse capability.
2. **Data Ingestion**
   - Uploaded `sales.csv` containing product sales records to the Lakehouse.
3. **Data Exploration**
   - Reviewed raw data tables and file structure.
4. **Visualization**
   - Built a **bar chart** comparing:
     - Y-axis: Product Items
     - X-axis: Sum of Quantity Sold

## 🔍 Key Features Demonstrated
- **Lakehouse Architecture**: Unified storage for structured/unstructured data
- **Power BI Integration**: Zero-export visualization
- **One-Click Transformations**: Data preparation without coding

## 📂 Files
- `sales.csv`: Sample sales data (provided in Microsoft Learn lab)
- `Fabric_Lab1.ipynb`: Optional notebook for analysis *(if applicable)*

## 💡 Takeaways
- Microsoft Fabric eliminates ETL complexity by combining:
  - Data engineering (Lakehouse)
  - Analytics (Power BI)
  - Collaboration (Workspaces)
